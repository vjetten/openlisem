Spatial modelling of land surface processes requires detailed spatial data to describe the surface. In openLISEM always a watershed or catchment with one outlet is modeled. The main input to define the catchment and the topography is a digital elevation model (DEM). From the DEM other variables and characteristics can be obtained, for example the local drain direction (LDD) the slope angle or channel dimensions. The DEM input for OpenLISEM should only contain data for the specific catchment and no data outside that. The quality, in terms of accuracy and resolution, of the DEM is of main important for the output quality of the simulations.
