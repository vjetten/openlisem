Advanced parameters

Parallel processing

All CPUs have more than 1 core that can be activated simultatneously for calculations. If the value is set at 0, all cores present are used. For small catchments this may not be faster (the overhead is more than the gain)!

Infiltration

  • Correct mass balance each timestep: use if for some combination of maps the overall mass balance is not so good. Check this option to divide the mass balance error over all pixels that have runoff (this timestep t) and the infiltration of the next timestep (t+1). This artificially spreads the error over all cells with activity.
  • Calculate the wetting front psi internally from pedotransfer functions, instead of a user defined map (EXPERIMENTAL)
  • Type of average k between layers: arithmetric, geometric, hamronic or minimum
  • Entry suction of water moving into the tile system in SWATRE. Zero (0) cm is saturration, a lower suction can move more water into the tile system, but the conductivity k is also lower. Determine this by trial and errror.
  • Apply Organic Matter correction and/or a Density Factor correction based on pedotransfer functions of Saxton and Rawls (2006). This is a way to include an affect of landuse that miomics a change in organic matter and soil structure. Ksat and Porosity are increased by an increase in OM or a lower relative bulk density. A decrease in OM and an increase in relative density (more compact) will decrease Ksat and Porosity. The default values are OM=3.5% and BD=1350 kg/m3. The OM correction is a direct percentage (between -2.0 and +2.0% organic matter) and Desnity Factor is a value between 0.9 (loose soil) and 1.2 (heavily compacted soil). Needs input maps OMcorr.map and densfact.map with these ranges of values)

Kinematic wave

  • Perimeter overland flow:chyeck when you want to use width+2*height (w+2h). Default is width only (unchecked). Old versions of LISEM had w+2h. In realty the contact surface perimeter is larger than w, depending on surface roughness.

Numerical parameters for dynamic flow

  • Riemann solver: smoothing functions that gives new states and fluxes on cell boundaries based on pressure and momentum differences. HLL are Harten-Lax-van Leer type solvers (def 4-HLL2c)
  • Max iterations: forces break out of n-th flood loop, usually not necessary, better to try different Courant conditions and minimum timesteps in the Flow tab (def 200).
  • Time average V: more stable solution of 2D flkow (default).
  • Do erosion outside 2D loop: The erosion calculations can be done inside the 2D flow using the chaning 2D timestep, or outsiode using the Lisem timestep (much faster). Try the inside loop option when results are unstable (def on).
  • Enable diagonal flow when blocked: water can be blocked in X and Y direction in 2D flow (a local depression, while a diagonal outlet exists. Diagonal outflows are not regarded in a 2D scheme. Enabling this uses the LDD to transport water and sediment to this diagonal cell. The threshold pit depth is set at 0.1 m. Can solve certain spurious pits that remain filled (def off).
  • Remove pits: set pit elevation to lowest surrounding cell in a 3x3 window (def. off)

Channel flow

  • Standard or hydraulic connection to channel: the standard connection is based on a fraction of the flow reaching the channel, based on overland flow velocity. The hydraulic connection is based on the maximum of hydraulic flow for a broad creatested weir and overland flow velocity, this is theoretically better (default).
  • Set channel max velocity: in some cases the channel velocity becomes excessive, limiting velocty.
